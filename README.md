# AWS-Windows-EC2-Practical


## Aim
To launch a Windows Server EC2 instance in AWS and establish a remote connection using Remote Desktop Protocol (RDP).

## Technologies Used
- Amazon Web Services (AWS)
- Amazon EC2
- Windows Server 2022
- Remote Desktop Connection (RDP)

## Procedure
1. Open AWS Management Console.
2. Navigate to EC2.
3. Launch a Windows Server instance.
4. Configure instance type and key pair.
5. Configure network settings and allow RDP on port 3389.
6. Launch the instance.
7. Retrieve the Administrator password.
8. Connect using Remote Desktop Connection.
9. Verify successful access to Windows Server.

## Output
Successfully launched and accessed a Windows Server EC2 instance remotely.
